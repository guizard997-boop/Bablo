# Мир канцелярии + Telegram-бот

## Что делает бот
1. Вы кидаете **фото** товара в Telegram
2. AI определяет, что на фото (если настроен OPENAI_API_KEY)
3. Вы присылаете **цену**
4. Товар появляется **на сайте**

## Переменные в Railway (Variables)

| Переменная | Обязательно | Описание |
|------------|-------------|----------|
| TELEGRAM_BOT_TOKEN | да | токен от @BotFather |
| SITE_URL | да | https://ваш-сайт.up.railway.app |
| OPENAI_API_KEY | нет | для распознавания фото |
| TELEGRAM_ADMIN_IDS | нет | ваш telegram id (только вы можете добавлять) |
| SECRET_KEY | желательно | секрет Flask |

## Как подключить

1. Откройте @BotFather → /newbot → получите токен
2. В Railway → Variables добавьте переменные выше
3. Задеплойте этот код
4. Откройте в браузере: https://ваш-сайт.up.railway.app/setup-webhook
5. Напишите боту /start и пришлите фото

## Узнать свой Telegram ID
Напишите боту @userinfobot — он покажет ваш id.
Добавьте его в TELEGRAM_ADMIN_IDS

## Без OPENAI_API_KEY
Бот всё равно работает: после фото просит название вручную, потом цену.
